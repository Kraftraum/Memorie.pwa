# Memorie.pwa

Memory – 36 Karten ist ein klassisches Konzentrations- und Paare-Spiel für einen Spieler. 
Auf einem 6×6-Feld liegen 36 verdeckte Karten. 
Ziel ist es, durch systematisches Aufdecken alle 18 Emoji-Paare zu finden. 

Das Spiel ist komplett offline spielbar, benötigt keine Installation und läuft im Browser – auf PC, Tablet und Smartphone.

Das Spiel lässt sich als Progressive Web App auf dem Homescreen installieren:

    Die App-URL im Chrome-Browser öffnen.
    Oben rechts auf ⋮ (drei Punkte) tippen.
    „Zur Startseite hinzufügen" bzw. „App installieren" antippen.
    Bestätigen → das Memory-Icon erscheint auf dem Homescreen.
